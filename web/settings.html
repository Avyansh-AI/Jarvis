OpenRouter Keys

Rotating keys live exclusively in .env on the hub as OPENROUTER_KEY_1, OPENROUTER_KEY_2, OPENROUTER_KEY_3 — they are never shown here and cannot be edited from any UI. Edit the file and restart the hub to change them. The boot preflight refuses to start if any of the three variables is missing.
